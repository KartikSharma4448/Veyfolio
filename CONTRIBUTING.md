# Contributing

Use the README setup instructions and keep changes focused on one behavior.
Discuss substantial API, template or dependency changes in an issue first.

## Before Submitting

- Run the frontend build and Jest tests.
- Run backend pytest tests after backend changes.
- Check both resume templates and desktop/mobile layouts after UI changes.
- Verify PDF page breaks for long resumes after export changes.
- Include regression tests when fixing a bug.
- Never include credentials, personal resume data, dependency folders or builds.

Describe the change, relevant issue and checks performed in your pull request.
Use fictional sample data for screenshots. Existing license terms apply.
